Use Case ID	UC-AUTH-001
Use Case Name	Single Sign-On Login
Actor		All Users (Taxpayer/MOR Staff)
Description	User logs into education portal using existing ITAS credentials
Priority	Critical
Preconditions	
1. User has active ITAS account
2. SSO is configured
Main Flow	
1. User clicks "Login" on education portal
2. Redirected to ITAS login page
3. User enters ITAS username/password
4. ITAS validates credentials
5. Returns authentication token
6. Education portal creates/updates user profile
7. Redirects to portal dashboard
Alternative Flow	Invalid credentials
User sees error message, can retry or reset password
Postconditions	User logged in with appropriate permissions
API Endpoint	POST /api/v1/auth/login


Use Case ID	UC-CM-001
Use Case Name	Upload/ Create Educational Resource
Actor	MOR Content Administrator
Description	Admin uploads new learning material (video, PDF, guide)
Priority	High
Preconditions	
1. Admin logged in with upload permissions
2. File is ready and approved
Main Flow	
1. Admin goes to Content Management
2. Clicks "Upload/Create New"
3. Selects file from computer
4. Fills metadata (title, category, tags, audience)
5. Clicks "Upload"
6. System validates and stores file
7. Shows success message
Validation Rules	• File types: PDF, MP4, PNG, JPG
• Max size: 100MB
• Required fields: Title, Category
Postconditions	Resource available in library, searchable

API Endpoint	POST /api/v1/content/upload

Use Case ID	UC-LMS-002
Use Case Name	Complete Learning Module
Actor	User
Description	User completes a module and takes assessment
Priority	High
Preconditions	
1. User enrolled in course
2. Module is available
Main Flow	
1. User opens module
2. Views all content (videos, reading)
3. Takes final quiz
4. System scores quiz
5. If passing score (≥70%):
• Marks module complete
• Updates progress
• Unlocks next module
6. If failing score:
• Shows incorrect answers
• Allows retry (max 3 attempts)
Postconditions	Progress updated, certificate generated if course complete
API Endpoint	POST /api/v1/lms/module/complete
